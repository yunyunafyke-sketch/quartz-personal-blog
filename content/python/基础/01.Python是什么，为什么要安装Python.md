## 一、💡 一句话理解

> [!tip] 核心结论
> Python 既是编程语言，也需要通过电脑上安装的 Python 解释器来执行。安装 Python，就是让电脑具备“读懂并运行 `.py` 代码”的能力。

## 二、🧭 Python 是什么

### 2.1 Python 是一种编程语言

Python 是人用来向电脑表达“要做什么”的一种语言。你把步骤写进以 `.py` 结尾的文件，例如：

```python
# 告诉电脑输出一段文字。
print("你好")
```

这段代码本身只是文本，还不能自动变成执行结果。

### 2.2 Python 解释器是什么

安装 Python 后，电脑中会多出一个通常名为 `python` 或 `python3` 的程序，它叫做 **Python 解释器（interpreter）**。

可以这样理解：

```text
你写的 .py 文件：任务说明书
Python 解释器：读懂、翻译并执行说明书的人
电脑：实际进行计算、读写文件或联网的机器
```

Python 官方教程说明，解释器可以读取并执行终端中输入的命令，也可以读取并执行指定的脚本文件。

## 三、⚙️ 为什么要安装 Python

### 3.1 运行自己写的代码

把下面内容保存为 `hello.py` 后，需要 Python 解释器才能运行：

```python
# 这是一个最小 Python 程序。
print("你好，Python")
```

在该文件所在目录执行：

```bash
# macOS / Linux 常用 python3；实际命令以本机安装结果为准。
python3 hello.py
```

预期输出：

```text
你好，Python
```

没有安装 Python 时，电脑不知道应由什么程序来执行 `hello.py`。

### 3.2 使用 `pip` 安装工具包

Python 安装通常也会提供 `pip`，用于安装别人已经写好的第三方库。例如，网络请求库 `requests`：

```bash
# 用当前 Python 对应的 pip 安装 requests。
python3 -m pip install requests
```

这让你不必从头编写所有功能，可以复用成熟库来处理网络请求、数据分析、网页开发等任务。

### 3.3 创建项目自己的 `.venv`

`.venv` 不是独立存在的，它必须由已经安装好的 Python 创建：

```bash
# 使用电脑中已安装的 Python，创建当前项目专属环境。
python3 -m venv .venv
```

这里的 `python3` 是基础 Python；`.venv` 是由它创建的项目专属运行环境。更多说明见 [[02.Python项目中.venv是什么]]。

## 四、🚀 实践：检查并开始使用

### 4.1 检查是否已安装

在终端执行：

```bash
# 查看 Python 版本；成功时会显示 Python 3 的版本号。
python3 --version
```

如果看到类似下面的结果，说明 Python 已安装：

```text
Python 3.12.x
```

### 4.2 在 PyCharm 中有什么作用

PyCharm 需要知道“用哪一个 Python 解释器运行当前项目”。你可以把它理解为：

```text
PyCharm：帮你编写、管理和运行代码的工具
Python 解释器：真正执行代码的引擎
.venv：当前项目专用的引擎和依赖区域
```

因此，PyCharm 项目通常会选择项目目录中的 `.venv` 作为解释器。这样运行代码和安装依赖都会限定在当前项目中。

### 4.3 最小验证

在终端依次执行：

```bash
# 1. 确认解释器存在并显示版本。
python3 --version

# 2. 进入交互模式；出现 >>> 表示 Python 正等待输入代码。
python3
```

接着输入：

```python
# 在 >>> 后输入这行，按回车即可立刻执行。
print("Python 可以运行")
```

预期结果：

```text
Python 可以运行
```

输入 `quit()` 可以退出交互模式。

## 五、📌 总结

- Python 是一种编程语言；Python 解释器是电脑执行这种语言的程序。
- `.py` 文件只是代码文本，安装 Python 后才能运行。
- `pip` 用于安装第三方库，也依赖 Python 环境。
- `.venv` 要基于已安装的 Python 创建，用来隔离不同项目的依赖。
- PyCharm 负责辅助开发，真正运行代码的是它所选中的 Python 解释器。
