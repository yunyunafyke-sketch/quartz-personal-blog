# 1 查询当前登陆用户可使用的角色权限列表（包含主动授权和岗位授权）

## 1.1 接口路径

```
import { services } from '@cic/mp-support';

services.queryRolePermissionList()
```

## 1.2 请求参数

无

## 1.3 响应格式

```
{
	"status": 1,
	"message": null,
	"data": [
		{
			"appId": "P010030",
			"roleId": "7043506528775483392",
			"roleCode": "RO_DOC_SystemAdministrator",
			"roleName": "文档中心系统管理员",
			"branchOrgCodeList": ["210000000000","211200000000"],
			"functionCodeList" :[
				"PP_OSD_BasicData_Organization_Export&Result", 
				"PP_OSD_BasicData_Organization_Export"
			],
			"isIncludeSubordinates":1
		}
	]
}
```

"isIncludeSubordinates" : 1机构权限包含下级；0机构权限不包含下级

# 2 根据应用ID查询当前登陆用户拥有的功能配置列表

## 2.1 接口路径

```
import { services } from '@cic/mp-support';

services.queryFunctionListByAppId({appId:'xxx'})
```

## 2.2 请求参数

|   |   |   |   |
|---|---|---|---|
|**参数**|**类型**|**描述**|必填|
|appId|String|应用ID|Y|

## 2.3 响应格式

```
{
  "status": 1,
  "message": null,
  "data": [
    "PP_OSD_BasicData_Organization_Export&Result", 
    "PP_OSD_BasicData_Organization_Export"
  ]
}
```

# 3 查询当前登陆用户应用负责人列表

## 3.1 接口路径

```
import { services } from '@cic/mp-support';

services.queryApplicationManagerList()
```

## 3.2 请求参数

无

## 3.3 响应格式

```
{
	"status": 1,
	"message": null,
	"data": [
		{
			"appId": "P010030",
			"ownerType": "appOwner"
		},
		{
			"appId": "P020030",
			"ownerType": "appTechOwner"
		}
	]
}
```

ownerType参数说明：

1. appOwner：应用管理员
2. appTechOwner：应用技术管理员
3. appBusinessOwner：应用业务管理员
