## 一、新增外包人员关联历史账号内容

#### 1、新增“历史账号信息”模块展示规则

（1）人员新增页面：不显示“历史账号信息”模块（需要触发校验规则，用户确定关联后才显示本模块）

（2）修改/详情页面：该外包人员曾关联过历史内部账号时显示本模块，只读，不可编辑

#### 2、保存校验规则

**（1）整体规则：**

| **校验规则名称**                                             | **校验逻辑**                                           | **前置条件**       |
| ------------------------------------------------------------ | ------------------------------------------------------ | ------------------ |
| 校验一：外包人员证件类型、证件号码与某个内部账号证件类型、证件号码一致 | 查询是否存在与外包人员证件类型、证件号码相同的内部账号 | 无                 |
| 校验二：外包人员与内部账号的归属机构一致                     | 比较外包人员的归属机构与校验一命中的内部账号的归属机构 | 命中校验一         |
| 校验三：内部账号的关联状态（校验已关联的情况）               | 查询当前内部账号是否已被其他外部账号关联               | 命中校验一、校验二 |
| 校验四：内部账号的在职状态（校验已离职状态的情况）           | 查询内部账号是否为离职状态                             | 命中校验一、校验二 |

- 校验顺序：校验一 → 校验二 → 校验三 → 校验四（逐级校验，前一级未命中则终止）

**（2）新增页面--校验流程**

   1）校验结果汇总弹窗显示规则：

- 命中校验一：显示校验汇总弹窗，弹窗中标识每条规则的命中状态（“已命中”/“未命中”）
- 未命中校验一：不显示校验汇总弹窗，直接保存

   2）校验结果汇总弹窗--场景与对应处理逻辑：

| **场景** | **命中校验规则**           | **弹窗类型**     | **提示语**                                                   | **操作按钮**                                                 |
| -------- | -------------------------- | ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 场景一   | 仅命中校验一               | 确认账号关联弹窗 | 当前账号与匹配的内部账号【姓名 - 账号】所属机构不一致，确认关联后，仅同步照片，非岗位权限、原账号业务数据无法同步。 | 点击确认关联，保存成功并关联点击取消关联，保存成功不关联点击右上角"X"，关闭弹窗，停留在当前页面 |
| 场景二   | 命中校验一、校验二         | 确认账号关联弹窗 | 当前账号匹配的内部账号【姓名 - 账号】，确认关联后将自动同步以下内容：非岗位权限、照片、原内部账号业务数据 | 点击确认关联，保存成功并关联点击取消关联，保存成功不关联点击右上角"X"，关闭弹窗，停留在当前页面 |
| 场景三   | 命中校验一、校验二、校验三 | 账号关联提示弹窗 | 当前匹配内部账号XXX（账号）已绑定外部账号【姓名 - 账号】。若该外包人员状态为已离场时，返聘操作优先复用当前外部账号。 | 点击我知道了，关闭弹窗，停留在当前页面点击右上角"X"，关闭弹窗，停留在当前页面 |
| 场景四   | 命中校验一、校验二、校验四 | 确认账号关联弹窗 | 匹配的内部账号【姓名 - 账号】已于XXXX-XX-XX离职。确认关联后，将自动同步以下内容：非岗位权限、照片、原内部账号业务数据注意：若离职日期超当月月底，将无法同步非岗位权限。 | 点击确认关联，保存成功并关联点击取消关联，保存成功不关联点击右上角"X"，关闭弹窗，停留在当前页面 |

**（3）  修改页面--校验流程**

关联过内部账号的不允许修改证件号码，置灰

--如果允许修改证件号码，可能会有重新关联的情况

没有关联过内部账号的可以修改证件号码，在修改页面保存的时候也需要走四个校验规则，进行判断



--非身份证的场景要考虑；证件类型和编码一致

#### 3、账号关联后的自动处理逻辑（入场审核通过后创建外部账号时触发）

| **处理项**             | **规则**                                                     | **其他**                                                     |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 手机号重复校验         | 关联的内外部账号之间不再做手机号重复校验                     |                                                              |
| 内部账号分配虚拟手机号 | 自动给关联的内部账号分配虚拟手机号关联账号间手机号不冲突，可不重新分配 |                                                              |
| 权限同步               | 岗位权限不自动同步，需要通过用户单独授权的方式处理（0723实现） --关联工作范围后可以自动同步（后续实现）非岗位权限的，自动同步内部账号的权限给外部账号。 | 用户组不允许授权给外部账号的要检验住用户组互斥或角色互斥不校验 |
| 照片同步               | 自动同步内部账号的照片给外部账号                             |                                                              |
| 关联关系存储           | 存储内部账号和外部账号的关联关系                             | 财险HRMS存储后发给账号中心对外查询的在账号中心               |
| HR系统数据推送         | 组织人员**不再接收（除离职外的）**HR系统推送的人员变更数据   | @张华                                                        |

#### 4、异常场景

关联失败的场景

虚拟手机号分配失败（例如号段资源不足/接口异常等）
部分权限分配失败（接口异常/创建外部账号时同步修改内部账号的权限等）
照片同步失败（接口异常/照片损坏）
