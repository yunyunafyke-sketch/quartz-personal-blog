## 情况 2：业务已在 HRMS 创建新账号并完成入场

### 场景说明

业务已在 HRMS 创建新账号并完成入场，此时 HRMS 人员记录已存在 `account_id`。需要将 HRMS 人员主键调整为账号中心的 `external_id`，同步关联的入离场申请记录，并补齐账号中心的账号来源和业务分类。

### 本次数据对应关系

| 项目                  | 原值                    | 目标值                     |
| ------------------- | --------------------- | ----------------------- |
| HRMS  ID            | `2097257980965810177` | `1812663075003961346`   |
| HRMS  account_id    | —                     | `zhex02888800139`       |
| HRMS picture        | —                     | `240912144236759490095` |
| HRMS contact_number | —                     | `18031218604`           |

### 刷数步骤

> 执行前请先按人员 ID、账号 ID 核对查询结果；以下均为写操作，建议在事务中执行并留存操作记录。

#### 1. 更新 HRMS 人员主数据

```sql
UPDATE outsourced_staff
SET id = '1812663075003961346',
    account_id = 'zhex02888800139',
    picture = '240912144236759490095',
    contact_number = '18031218604'
WHERE id = '2097257980965810177';
```

#### 2. 更新 HRMS人员明细表

```sql
UPDATE outsourced_staff_onoffboard_application_record
SET account_id = '1812663075003961346'
WHERE account_id = '2097257980965810177';
```


#### 3. 更新 HRMS 人员异动记录

```sql
UPDATE outsourced_staff_movement
SET staff_id = '1812663075003961346',
    account_id = 'zhex02888800139'
WHERE staff_id = '2097257980965810177';
```

#### 4. 更新账号中心（SSO）账号表

将账号中心中该账号的来源和业务分类更新为 HRMS 对应值。

```sql
UPDATE t_abs_sso_account
SET external_source = 'P010068',
    external_classification = 'LY02'
WHERE account_id = 'zhex02888800139';
```
