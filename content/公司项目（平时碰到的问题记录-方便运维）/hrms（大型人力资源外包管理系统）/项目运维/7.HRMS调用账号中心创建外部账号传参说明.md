# HRMS 调用账号中心创建外部账号传参说明

## 1. 调用场景

外包人员入场审批通过后，HRMS 会判断人员是否已经存在 `accountId`：

- `accountId` 有值：调用账号中心的外部账号返聘接口。
- `accountId` 为空：组装 `ExternalAccountAddCmd`，调用账号中心创建外部账号。

创建成功后，账号中心返回新账号的 `accountId`，HRMS 将其回填到外包人员记录中。

## 2. RPC 调用

HRMS 最终调用：

```java
accountRpcFacade.createExternalAccount(externalAccountAddCmd)
```

HRMS 内部封装方法：

```java
accountIntegration.createExternalAccount(addCmd)
```

请求对象类型为：

```java
ExternalAccountAddCmd
```

## 3. 创建账号请求参数

| 字段 | HRMS 传值 | 说明 |
| --- | --- | --- |
| `externalId` | `staffEntity.getId()` | 外包人员 ID |
| `displayName` | `staffEntity.getStaffName()` | 外包人员姓名 |
| `joinCompDt` | 入场申请日期 | 格式为 `yyyy-MM-dd` |
| `leaveCompDt` | `9999-12-31` | 新账号默认离场日期 |
| `phoneNo` | `staffEntity.getContactNumber()` | 联系电话 |
| `externalSource` | `P010068` | HRMS 外部账号来源编码 |
| `branchOrgCode` | `staffEntity.getBranchOrgCode()` | 分支机构编码 |
| `customCode` | `staffEntity.getOperatingOrgCode().substring(2, 6)` | 操作机构编码的第 3～6 位 |
| `externalClassification` | `staffEntity.getBusinessCategory()` | 业务分类 |
| `faceId` | `staffEntity.getPicture()` | 人脸照片或图片标识 |
| `externalHead` | `staffEntity.getCreator()` | 外包人员记录创建人 |
| `relatedAccountId` | `staffEntity.getRelatedAccountId()` | 关联的历史内部账号 ID；没有关联时可能为空 |

其中，HRMS 账号来源常量定义为：

```java
public static final String EXTERNAL_SOURCE_HRMS = "P010068";
```

## 4. 当前组装代码

```java
ExternalAccountAddCmd addCmd = new ExternalAccountAddCmd();

LocalDate offboardLocalDate = LocalDate.of(9999, 12, 31);
Date offboardDate = Date.from(
        offboardLocalDate.atStartOfDay(ZoneId.systemDefault()).toInstant());

addCmd.setExternalId(staffEntity.getId())
        .setDisplayName(staffEntity.getStaffName())
        .setJoinCompDt(DateUtil.format(applicationDate, "yyyy-MM-dd"))
        .setLeaveCompDt(DateUtil.format(offboardDate, "yyyy-MM-dd"))
        .setPhoneNo(staffEntity.getContactNumber())
        .setExternalSource(EXTERNAL_SOURCE_HRMS)
        .setBranchOrgCode(staffEntity.getBranchOrgCode())
        .setCustomCode(staffEntity.getOperatingOrgCode().substring(2, 6))
        .setExternalClassification(staffEntity.getBusinessCategory())
        .setFaceId(staffEntity.getPicture())
        .setExternalHead(staffEntity.getCreator())
        .setRelatedAccountId(staffEntity.getRelatedAccountId());
```

## 5. 返回值及异常处理

- 创建成功：账号中心返回新建的账号 ID，HRMS 将其保存到外包人员的 `accountId`。
- 创建失败：HRMS 读取账号中心返回的错误码和错误信息，并抛出 `BizRuntimeException`。

## 6. 运维排查要点

遇到入场创建账号失败时，重点核对：

1. `operatingOrgCode` 是否有值且长度不少于 6 位，否则截取 `substring(2, 6)` 时会发生异常。
2. 手机号、分支机构编码、业务分类及图片标识是否正确。
3. `externalId` 是否已经在账号中心存在。
4. 需要关联历史内部账号时，`relatedAccountId` 是否正确传入。
5. 日志中的 `createExternalAccount request` 和账号中心返回结果是否包含明确错误码。
