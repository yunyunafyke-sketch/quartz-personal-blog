# 修改 externalId（externalId 和 accountId 不一致）

## 1. SSO 修改

### 1.1 查询

```sql
SELECT account_id, display_name, external_id FROM t_abs_sso_account WHERE account_id = 'zhex08330100019';
```

### 1.2 查询结果

| account_id | display_name | external_id |
| --- | --- | --- |
| `zhex08330100019` | 李寒浠 | `2089247411306360833` |

### 1.3 修改

```sql
UPDATE t_abs_sso_account SET external_id = 'zhex08330100019' WHERE account_id = 'zhex08330100019';
```

## 2. 财险 HRMS 数据确认

```sql
SELECT * FROM outsourced_staff WHERE id = 'zhex08330100019';

SELECT * FROM outsourced_staff_movement WHERE account_id = 'zhex08330100019';

SELECT * FROM outsourced_staff_onoffboard_application_record WHERE account_id = '2089247411306360833';
```

## 3. 财险 HRMS 修改

```sql
UPDATE outsourced_staff SET id = 'zhex08330100019' WHERE account_id = 'zhex08330100019';

UPDATE outsourced_staff_movement SET staff_id = 'zhex08330100019' WHERE account_id = 'zhex08330100019';

UPDATE outsourced_staff_onoffboard_application_record SET account_id = 'zhex08330100019' WHERE account_id = '2089247411306360833';
```
