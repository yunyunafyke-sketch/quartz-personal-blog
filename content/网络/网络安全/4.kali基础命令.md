# Kali 基础命令与 Wifite 扫描说明

> 常用命令速查：切换管理员权限、查看网络接口，以及阅读 Wifite 的扫描与监听状态。

## 一、命令速查

| 命令 | 用途 | 关注点 |
| --- | --- | --- |
| `sudo su` | 切换到超级管理员 | 提示符通常从 `$` 变为 `#` |
| `ifconfig` | 查看网络接口信息 | 网卡名称与 `UP` / `DOWN` 状态 |
| `sudo wifite` | 启动无线网络安全测试工具 | 扫描列表、目标选择与监听状态 |

## 二、管理员权限：sudo su

```bash
sudo su
```

- **作用**：切换到超级管理员（root）。
- **识别方式**：终端提示符通常从 `$` 变成 `#`。
- **密码输入**：输入密码时，终端不会显示字符，输完直接按回车。

> [!note] 关于密码
> 原笔记记录的默认密码为 `kali`；实际应以当前系统的账户配置为准。

## 三、网络接口：ifconfig

```bash
ifconfig
```

重点查看以下信息：

| 检查项 | 示例 | 说明 |
| --- | --- | --- |
| 无线网卡名称 | `wlan0` | 注意末尾是数字 `0`，不是字母 `O` |
| 接口状态 | `UP` / `DOWN` | 判断接口是否处于启用状态 |

## 四、Wifite 扫描与状态说明

### 4.1 启动与选择目标

```bash
sudo wifite
```

1. 启动后，工具扫描周围无线网络，并显示带编号的列表。
2. 按 `Ctrl + C` 停止扫描，进入目标选择提示。
3. 根据提示输入网络编号；多个编号可以用逗号或连字符分隔，也可以输入 `all`。

**截图中的 `1`** 是操作者输入的网络编号。

### 4.2 扫描列表字段说明

| 字段              | 含义                       | 怎么看                                                               |
| --------------- | ------------------------ | ----------------------------------------------------------------- |
| `NUM`           | 当前扫描列表中的编号               | 选择目标时输入这个编号，例如 `1`；它不是设备的固定标识。                                    |
| `ESSID`         | 无线网络名称，也就是通常看到的 Wi-Fi 名称 | 名称未知时，可能显示括号包围的设备地址（BSSID）；乱码可能与名称编码有关。                           |
| `CH`            | 无线网络使用的信道（Channel）       | 例如 `1`、`6`、`11`、`149`；这是信道编号，不是连接人数。                              |
| `ENCR`          | 无线网络的加密与认证类型             | 截图中的 `WPA2-P` 表示 WPA2 个人版，`WPA3-S` 表示 WPA3 的 SAE 认证，`OPN` 表示开放网络。 |
| `PWR` / `POWER` | 接收到的无线信号强度               | 截图这种正数显示通常数值越大，信号越强，例如 `53db` 比 `24db` 强；不要直接当成真实的正数 dBm。         |
| `WPS` / `WPS?`  | Wi-Fi 简易配置功能的检测状态        | `yes`：检测到 WPS 且未锁定；`no`：未检测到 WPS；`lock`：WPS 已锁定；`n/a`：状态未知。       |
| `CLIENT`        | 扫描时发现的关联客户端数量            | 例如 `2` 表示发现两个客户端；空白或 `0` 表示暂未发现，不代表一定没有设备连接。                      |

> [!tip] 信号强度的两种显示方式
> Wifite 的部分版本会把负数信号值加上 `100` 后显示，例如 `-47 dBm` 显示为 `53db`。如果其他工具直接显示负数 dBm，则越接近 `0`，信号越强，例如 `-47 dBm` 强于 `-76 dBm`。

字段显示与状态说明参考：[Wifite 扫描列表源码](https://github.com/derv82/wifite2/blob/master/wifite/util/scanner.py)、[目标信息与信号显示源码](https://github.com/derv82/wifite2/blob/master/wifite/model/target.py)。不同版本的列名和缩写可能略有差异。

### 4.3 常见状态解读

| 状态提示                               | 含义                                    |
| ---------------------------------- | ------------------------------------- |
| `Skipping PMKID attack`            | 截图所示情况为缺少相关工具，因此跳过 PMKID 测试。          |
| `WPA Handshake capture: Listening` | 正在监听设备连接热点时的认证过程；握手数据不直接包含明文密码。       |
| `clients: 0`                       | 目前没有发现连接该热点的客户端。                      |
| `deauth: 14s`                      | 与断开认证操作有关的计时；这类操作会尝试让设备断线重连，可能干扰正常连接。 |
| `timeout: 3m39s`                   | 本轮捕获剩余的等待时间。                          |
