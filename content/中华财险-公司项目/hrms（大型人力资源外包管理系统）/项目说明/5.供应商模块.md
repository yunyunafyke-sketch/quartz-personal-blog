## 一句话理解

供应商就是 HRMS 里维护的外包公司档案：保存“这家公司是谁、由谁管理、钱打到哪里、留了哪些材料”；其中机构基础资料以客户域为来源，HRMS 保存一份业务快照。

## 供应商主要存哪些东西

| 类别     | 保存内容                  | 用途               |
| ------ | --------------------- | ---------------- |
| 身份标识   | 本地 `id`、客户域账号 ID | 标识本地供应商，并关联客户域机构 |
| 公司基础资料 | 公司名称、证件类型/号码、注册地址     | 识别供应商主体          |
| 联系人资料  | 联系人姓名、手机号             | 日常联系             |
| 管理归属   | 管理机构代码                | 确定由哪个组织负责管理      |
| 结算资料   | 支付信息、银行账户             | 协议和结算相关业务使用      |
| 附件     | 营业资料等文件的文件 ID、文件名     | 留档和在线预览          |
| 审计信息   | 最后操作人、操作时间、有效标识       | 追踪资料变更和有效状态      |

此外，供应商会被协议和外包人员引用：协议中的乙方、外包人员所属供应商，都会关联供应商 ID。

## 这些数据从哪来

| 数据                          | 主要来源          | 说明                                                    |
| --------------------------- | ------------- | ----------------------------------------------------- |
| 客户域账号 ID、公司名称、证件、地址、联系人、手机号 | 客户域机构资料       | 建档前可查询回填；客户域资料变更后，消息会同步更新 HRMS 的名称、注册地址、联系人和手机号等本地快照。 |
| 管理机构                        | HRMS 管理员填写/选择 | HRMS 实际保存机构代码；展示名称时再从组织系统查询。                          |
| 支付和银行账户                     | HRMS 管理员维护    | 由供应商建档、编辑时录入。                                         |
| 附件                          | HRMS 管理员上传    | HRMS 保存附件关联和文件信息，文件预览由文档中心处理。                         |
| 最后操作人姓名                     | 账号系统          | HRMS 保存操作账号，查询页面时补充显示姓名。                              |

## 字段映射

| HRMS 供应商字段 | 对应来源 | 获取/映射规则 |
| --- | --- | --- |
| `id`（对外通常称 `supplierId`） | HRMS | 新增供应商时由 HRMS 生成；它不是客户域账号 ID。 |
| `customer_domain_id` | 客户域账号 ID | 建档时传入，用于关联客户域机构。 |
| `name` | 客户域证件资料 | 按建档传入的证件类型匹配客户域证件，取 `cusFullName`。 |
| `certificate_type` | 客户域证件资料 | 取匹配的证件类型。 |
| `certificate_number` | 客户域证件资料 | 取匹配的证件号码。 |
| `supplier_address` | 客户域地址 | 取地址类型为 `0701205` 的注册地址。 |
| `supplier_person_name` | 客户域关系人 | 取关系类型为 `05` 的联系人姓名。 |
| `supplier_phone_number` | 客户域联系人方式 | 在上述联系人下取联系方式类型为 `0700602` 的手机号。 |
| `manage_operation_org_code` | HRMS 管理端 | 建档/编辑时选择并保存机构代码；机构名称由组织系统查询补充。 |
| `payment_method`、银行账户相关字段 | HRMS 管理端 | 建档/编辑时人工填写维护，不从客户域同步。 |
| 附件（`attachment` 表） | HRMS 上传文件 | 以 `biz_id = supplierId`、`type = supplier` 关联。 |
| `creator`、`modifier` | HRMS 登录账号 | HRMS 保存账号 ID；页面显示姓名时由账号系统补充。 |

> 注意：客户域消息只会覆盖名称、注册地址、联系人和手机号；证件信息、管理机构和银行付款资料仍由 HRMS 本地维护。编辑供应商时，请求虽包含 `customerDomainId`，但当前实现不会更新该字段。

## 最简数据流

```text
1. 管理员录入或选择客户域组织
   → `query-customer-detail` 调客户域，回填名称、证件、地址、联系人、手机号。
2. 管理员补充管理机构、银行账户和附件
   → `add-supplier` / `update-supplier`，写入 `supplier` 表及附件表。
3. 客户域后续发生组织资料变更
   → SOFAMQ `TP_CIC_CUST_ORG_CHANGE_CORE`
   → 按“证件类型 + 证件号 + 客户域 ID”定位本地供应商
   → 更新名称、注册地址、联系人、手机号。
4. 协议、外包人员等业务
   → 使用本地供应商 `id` 关联供应商。
```
