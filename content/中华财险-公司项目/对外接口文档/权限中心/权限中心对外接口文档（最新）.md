# 7. 根据角色+归属机构（自动包含本下级）获取被授权的账号列表

注：本接口返回的结果较最新数据有一小时延迟，历史数据无影响

## 7.1. 接口功能

根据角色列表+归属机构（本下级）获取被授权的账号列表，主动授权、用户组授权和岗位授权对应的人员清单

（机构匹配归属机构包含本下级）

最多返回2000条，先查单独授权够2000直接返回，不够再查用户组授权补充，不够再查岗位授权补充

例：角色a授权账号b（账号b的归属机构杭州分），输入浙江分可查出账号

## 7.2. 接口路径

|   |   |
|---|---|
|**_包名_**|com.aliyun.fsi.insurance.acl.rpc|
|**_类名_**|AccountPermissionRpcFacade|
|**_函数名_**|getRoleMembersByBranchOrgIncludeChild|

## 7.3. 请求参数

**RoleMemberBatchReqDTO：**

|   |   |   |   |
|---|---|---|---|
|**参数**|**类型**|**是否必填**|**描述**|
|branchOrgCodeList|List<String>|是|机构编码（最多5个）|
|roleCodeList|List<String>|是|角色编码（最多5个）|

```
{
	"branchOrgCodeList":["210000000000"],
	"roleCodeList":["RO_RPM_Config"]
}
```

## 7.4. 响应格式

|   |   |
|---|---|
|**_包名_**|com.aliyun.fsi.insurance.acl.rpc|
|**_类名_**|UserDefineRoleGroupRpcFacade|
|**_函数名_**|getUserDefineRoleGroupMember|

### 12.2.2. 请求参数

**UserDefineRoleGroupMemberReqDTO:**

|   |   |   |   |
|---|---|---|---|
|**参数**|**类型**|**是否必填**|**描述**|
|userDefineRoleGroupCode|String|是|用户组编码|

```
{
```

## 12.3. 根据成员账号批量查询所属用户组

### 12.3.1. 接口路径

|   |   |
|---|---|
|**_包名_**|com.aliyun.fsi.insurance.acl.rpc|
|**_类名_**|UserDefineRoleGroupRpcFacade|
|**_函数名_**|getUserDefineRoleGroupInfoByAccId|

### 12.3.2. 请求参数

|   |   |   |   |
|---|---|---|---|
|**参数**|**类型**|**是否必填**|**描述**|
|accIdList|List<String>|是|账号列表(单次请求不超过100条)|

### 12.3.3. 响应格式

**UserDefineRoleGroupMemberResDTO**：

|   |   |   |
|---|---|---|
|**参数**|**类型**|**描述**|
|accId|String|账号|
|userDefineRoleGroupSimpleResDTOList|List<userDefineRoleGroupSimpleResDTOL>|用户组信息|

**UserDefineRoleGroupSimpleResDTO**:

|   |   |   |
|---|---|---|
|**参数**|**类型**|**描述**|
|name|String|用户组名称|
|code|String|用户组编码|
|appId|String|归属应用ID|

示例：

```
{
	"status": 1,
	"message": null,
	"data": [
		{
			"accId":"1010001111",

					},
					{
							"name": "用户组1",
							"code": "code2",

					}
			]
		}
	]
}
```
