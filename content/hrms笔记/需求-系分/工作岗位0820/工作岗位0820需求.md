<font style="background-color:#FBDE28;">（2）规则</font>

+ <font style="color:rgba(0, 0, 0, 0.85);">新增/修改页面支持对工作岗位信息进行继续新增/编辑/删除</font>
+ <font style="color:rgba(0, 0, 0, 0.85);">系统操作新增人员时支持关联工作岗位</font>
+ <font style="color:rgba(0, 0, 0, 0.85);">批量新增导入模板中不支持关联工作岗位，需要导入后维护；若未维护，需要在入场申请页面【提交】时，需要对本此次入场的人员进行全部拦截，并给出校验提示“XX、XX未关联工作岗位，请关联后再办理入场”（XX未人员名称）</font>
+ <font style="color:rgba(0, 0, 0, 0.85);">工作岗位的新增、修改、删除均需要记录在人员的任职记录表中</font>
+ <font style="color:rgba(0, 0, 0, 0.85);">外包账号关联内部账号时，只做非岗位授权的复制，不做岗位授权的复制，岗位授权需要按照外包账号关联的工作岗位进行授权</font>

2、岗位权限弹窗

（1）点击外包人员页面的【工作岗位】时，显示岗位权限弹窗，平铺展示该工作岗位对应的职能、用户组等信息

（2）岗位权限弹窗内容：工作岗位名称、工作岗位编码、职能名称、职能编码、用户组名称、用户组编码；

         其中用户组名称支持点击，点击显示角色清单弹窗；其余字段均为只读；岗位权限列表支持分页

3、角色清单弹窗

（1）点击岗位权限中某一【用户组名称】时，显示角色清单弹窗，平铺展示该用户组下已分配的角色清单

（2）角色清单弹窗内容：

+ 查询条件：角色名称（搜索框，支持模糊查询）、角色归属应用（下拉单选，取运营支撑应用管理的数据吗？）
+ 列表字段：序号、角色名称、角色编码、角色归属应用；角色清单列表支持分页
