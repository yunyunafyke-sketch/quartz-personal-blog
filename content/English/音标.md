## 一、🔊 重点练习音标

不用一次练完全部音标。先按下面顺序练，尤其注意带 ⭐ 的音标。

### 1.1 元音

| 音标 | 例词 | 重点 |
| --- | --- | --- |
| ⭐ `/iː/` | sheep, eat | 长音“衣” |
| ⭐ `/ɪ/` | ship, it | 短音，嘴巴更放松 |
| ⭐ `/e/` | bed, men | 短元音 |
| ⭐ `/æ/` | bad, man | 嘴巴张大 |
| `/ʌ/` | cup, love | 短而放松 |
| `/ɑː/` | car, father | 长元音，英式常见 |
| `/uː/` | food, moon | 长音“乌” |
| ⭐ `/ʊ/` | good, book | 短音，不能读成 `/uː/` |
| `/ɜː/` | bird, work | 英式英语常见 |
| `/ə/` | about, ago | 弱读音，轻轻带过 |

### 1.2 双元音

| 音标 | 例词 |
| --- | --- |
| `/eɪ/` | name, day |
| ⭐ `/aɪ/` | like, time |
| `/əʊ/`（英式）或 `/oʊ/`（美式） | go, home |
| `/aʊ/` | now, house |
| `/ɔɪ/` | boy, enjoy |

### 1.3 容易混淆的辅音

| 音标 | 例词 | 练习重点 |
| --- | --- | --- |
| ⭐ `/θ/` | think, three | 舌尖轻放在上下牙之间，不振动声带 |
| ⭐ `/ð/` | this, they | 舌位同上，但要振动声带 |
| ⭐ `/r/` | right, red | 舌头不要碰到上颚 |
| ⭐ `/l/` | light, like | 舌尖碰上齿龈 |
| ⭐ `/v/` | very, vest | 上齿轻碰下唇，振动声带 |
| ⭐ `/w/` | we, west | 双唇先收圆再展开 |
| `/n/` | sin, night | 舌尖发音 |
| ⭐ `/ŋ/` | sing, long | 舌根发音，不要额外读出 `/g/` |
| `/s/` | rice, bus | 不振动声带 |
| `/z/` | rise, is | 振动声带 |
| `/ʃ/` | she, ship | 类似“嘘”的声音 |
| `/ʒ/` | vision, usually | 轻微振动的“sh”音 |
| `/tʃ/` | cheap, watch | 类似“吃”的音 |
| `/dʒ/` | jeep, age | 类似“知”的音 |

## 二、⭐ 最先练这 10 组

每天练 2 组，不要贪多：

```text
/iː/  /ɪ/       sheep / ship
/e/   /æ/       bed / bad
/uː/  /ʊ/       fool / full
/θ/   /s/       think / sink
/ð/   /z/       this / zis
/r/   /l/       right / light
/v/   /w/       vest / west
/n/   /ŋ/       sin / sing
/s/   /z/       rice / rise
/tʃ/  /dʒ/      cheap / jeep
```

## 三、📝 每个音标的练习方法

1. 点击音标，先听标准发音。
2. 听例词，观察嘴型和舌头位置。
3. 每个音单独读 5 次。
4. 每个例词读 5 次。
5. 把例词放进句子里读。
6. 录音，再和标准发音对比。

例如练习 `/iː/` 和 `/ɪ/`：

```text
sheep / ship
I see a sheep.
I see a ship.
```
