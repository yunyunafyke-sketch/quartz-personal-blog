# 青岛三日游行程攻略

> 行程基调：Day 1 慢逛老城，Day 2 登崂山看海，Day 3 严格控时赶 18:00 航班。第三天下午的唯一优先级是 **15:50 前从啤酒博物馆出发去青岛胶东国际机场**。

## Day 1｜老城文艺线

以步行为主，行程不塞景点，留足拍照和看海时间。

| 时间 | 安排 | 提醒 |
| --- | --- | --- |
| 09:00–10:00 | 栈桥 | 早点到，光线和人流都更友好。 |
| 10:15–11:30 | 圣弥厄尔大教堂 | 以外景拍摄为主，控制停留。 |
| 11:30–13:15 | 中山路午饭 | 选前海沿或 1937 青岛老味道，饭后顺路逛一小段。 |
| 13:30–15:00 | 福山支路 | 慢走拍老建筑与街景。 |
| 15:15–16:30 | 琴屿路 | 沿海散步、拍小青岛方向。 |
| 16:40–18:30 | 小青岛公园 | 海边等待日落；视日落时间可提前或延后 20 分钟。 |
| 晚上 | 返回中山路酒店 | 不额外安排夜游，给第二天崂山留体力。 |

## Day 2｜崂山仰口、小麦岛与灯光秀

| 时间 | 安排 | 提醒 |
| --- | --- | --- |
| 07:20 | 中山路酒店出发前往仰口 | 建议提前准备水、零食、防晒和轻便外套。 |
| 08:30–14:00 | 仰口景区 | 往返索道；下山后不要在景区久等用餐。 |
| 14:30 | 返程回市区 | 车上补水、简单补给。 |
| 16:00–17:20 | 小麦岛公园 | 看海、草坪、拍照；卡住 17:20 离开。 |
| 17:30–18:40 | 五四广场 | 以地标打卡和沿海步道为主。 |
| 18:50–19:15 | 打车至第三海水浴场 | 预留堵车；目标 19:15 前抵达。 |
| 19:30–21:00 | 第三海水浴场灯光秀 | 结束前即可预约返程网约车。 |
| 21:00 后 | 返回中山路 | 散场叫车紧张，提前预约，避免现场临时叫车。 |

## Day 3｜八大关、太平山索道、啤酒博物馆、胶东机场

### 时间策略

原计划 16:20 才结束啤酒博物馆，再打车约 1.5 小时去机场，抵达时间接近航班起飞，风险很高。压缩后的安排将博物馆游览控制在 90 分钟，并在 **15:50 准时出发**；即使遇上晚高峰，也尽量能在 17:20 左右到达机场。

| 时间 | 安排 | 硬性要求 |
| --- | --- | --- |
| 10:00–12:00 | 八大关 | 仅走梧桐大道、花石楼外景、第二海水浴场；两小时到点即走。 |
| 12:10–13:00 | 太平山观光索道 | 中山公园站上，只买「中山公园 → 太平山」单程票。排队超过 15 分钟或大风停运，立即跳过。 |
| 13:05–13:35 | 就近简餐 | 快餐、面包、便利店补给均可；不安排正餐。 |
| 13:35–14:00 | 前往青岛啤酒博物馆 | 路上完成预约核验，14:00 前到馆。 |
| 14:00–15:30 | 青岛啤酒博物馆 | 只走核心动线：主展厅 → 原浆啤酒体验 → 啤酒豆；不逛文创店、不排额外互动。 |
| 15:30–15:40 | 洗手间、取行李、叫车 | **15:40 必须离馆。** |
| 15:50 | 出发前往青岛胶东国际机场 | **最晚不可晚于 16:00。** 建议提前预约专车/网约车。 |
| 约 17:20 | 抵达机场 | 直奔值机或托运柜台，随后安检。 |
| 18:00 | 航班起飞 | 若需托运行李或尚未线上值机，更应确保 15:50 出发。 |

### 机场兜底规则

- 15:00 仍未进入啤酒博物馆：放弃参观，直接去机场或在附近短暂停留后出发。
- 15:40 尚未离馆：立即结束所有购物和体验，先上车再说。
- 16:00 仍未上车：改用更快的叫车方案，必要时直接从博物馆前往机场，不再安排任何中途停留。
- 已办理线上值机、无托运行李，仍不能替代预留的交通缓冲；第三天不要把“多玩一会儿”建立在赌路况上。

## 出行清单

- Day 2：舒适鞋、防晒、饮用水、充电宝、轻便外套；崂山天气变化快。
- Day 3：提前完成线上值机；登机牌、身份证、充电宝放在易取位置；行李尽量在中山路酒店寄存或随身精简。
- 预约：啤酒博物馆提前在公众号购票；第三天从博物馆前往机场的车辆建议在 15:30 前确认。
