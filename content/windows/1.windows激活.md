本文整理原有的 Windows 激活操作步骤，便于按顺序查看和复制命令。

> [!note] 使用前说明
> 以下保留原文中的产品密钥和 KMS 地址，未验证其有效性。KMS 激活应使用你有权使用的组织授权和服务器。

## 1. 打开管理员终端

右键点击任务栏的 **开始** 图标，选择 **Windows PowerShell（管理员）** 或 **命令提示符（管理员）**。

## 2. 安装产品密钥

复制以下命令，粘贴到管理员终端，按 **Enter** 执行：

```powershell
slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
```

## 3. 设置 KMS 服务器

等待上一步完成后，执行：

```powershell
slmgr /skms kms.03k.org
```

## 4. 发起激活

执行以下命令，等待系统返回激活结果：

```powershell
slmgr /ato
```

> [!tip] 操作顺序
> 按照 **安装产品密钥 → 设置 KMS 服务器 → 发起激活** 的顺序逐条执行，并查看每一步的提示。
