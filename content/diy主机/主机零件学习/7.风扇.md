## 一、💡 先建立判断标准

> [!tip] 核心结论
> 风扇的价值是在安装位置的实际阻力下，以可接受的噪声推动需要的空气。尺寸、最高转速、最大风量、最大静压和数量，都不能单独决定整机散热效果。

本文延续 [[6.散热|散热]]，专门讲风扇的规格、选型、方向、接线和调速。主线案例是你记录中的乔思伯 ZA-240B／ZA-240BR，以及爱国者极光 Z13PRO 正叶／反叶组合。

资料核对日期：2026-10-25。产品参数示例用于学习，不构成实时价格排行；没有把订单信息推断为实际装机方向或性能实测。

## 二、🧭 理论：风扇具体做什么

### 2.1 它搬运空气，不直接制造低温

风扇推动空气，让空气经过发热部件或散热表面，并帮助机箱与房间交换空气。散热器把热交给空气，风扇帮助把这些空气带走。

可以把风扇理解成运送空气的设备，把滤网、冷排和狭窄进风口理解成运输阻力。这个类比帮助理解风量和静压，但实际气流会有回流、湍流与泄漏，不能当作密封水管。

普通机箱风扇不能把室内空气本身变冷。热风反复在机箱附近被吸回去，或者进风口被挡住，单纯加速也未必解决问题。

### 2.2 机箱扇、冷排扇、塔扇的区别

| 使用位置 | 面对的主要条件 | 选型重点 |
| --- | --- | --- |
| 较开放的机箱进／排风口 | 相对较低阻力 | 实际风量、噪声与调速范围 |
| 带密集滤网或狭窄面板的进气位 | 有明显进气阻力 | 受阻时风量、静压曲线与噪声 |
| 水冷冷排 | 风需要穿过密集鳍片 | 对应冷排阻力下的表现与密封接触 |
| 风冷散热塔 | 鳍片、风扇夹与内存空间限制 | 实际风压／风量、尺寸和固定兼容 |

“机箱扇”和“冷排扇”不是绝对不能通用的两种电器。应看具体风扇在对应阻力下的工作能力，不按宣传名称一刀切。

## 三、🔎 理论：型号与尺寸怎么看

### 3.1 一条常见规格怎样拆

以 **120×120×25mm、4-pin PWM、200–1800RPM、ARGB** 这种描述为例：

| 字段 | 含义 | 不能据此推断什么 |
| --- | --- | --- |
| 120×120mm | 框体长宽规格 | 与 140mm 孔位并不自动通用 |
| 25mm | 框体厚度 | 所有 120mm 扇并非都同厚度 |
| 4-pin PWM | 常见电机供电、测速与控制接口 | 与 4-pin RGB 灯效接口不是同一种东西 |
| 200–1800RPM | 标称转速范围 | 不保证在所有控制器上都能实现相同最低转速 |
| ARGB | 可寻址灯效能力 | 不表示电机一定支持 PWM |
| Reverse／反叶 | 叶片气流设计变体 | 不等于安装到机箱后永远只能进风 |

真实产品还要记录完整料号、电机额定电压／电流、灯效接口、连接方式与配套控制器需求。

### 3.2 120、140、大风扇、薄风扇怎么选

140mm 风扇有更大的叶轮空间，有机会以较低转速提供所需气流，但具体设计、阻力和噪声仍需比较，不能认定所有 140 都胜过 120。

15mm 左右的薄扇可以帮助紧凑装机，但厚度减少也改变叶片和电机设计空间。能装得下只是第一关，还要验证目标负载。

有的风扇外框尺寸与安装孔规格并不完全按常见关系对应，联框产品还要查总长度、线缆和卡扣空间。购买前以尺寸图和机箱／冷排说明为准。

### 3.3 PWM、PST、Pro、Max：后缀不是统一分数

PWM 描述调速机制；PST 是 ARCTIC 的风扇控制信号共享命名；其他厂商的一线串联、磁吸或拼接系统，可能使用不同结构和专有接口。

Pro、Max、Silent、RGB、反叶等是区分产品的线索，不构成跨品牌的性能等级。不能把类似名字的不同代际规格混用。

## 四、⚙️ 理论：核心参数为什么有用

### 4.1 转速 RPM：快转通常能加强气流，也会改变噪声

RPM 是每分钟转数。同一把风扇提高转速，通常能增加风量与压力能力，也会增加噪声与耗电。

但两把风扇同为 1500RPM，不代表风量、风压和声音相同。尺寸、叶片、电机、轴承、框体和安装阻力都会改变结果。

最高 3000RPM 的风扇可能在低转速下很好用，也可能并不适合你所需的安静区间。要看完整调速与噪声表现，不只看最高值。

### 4.2 风量 CFM：每段时间能搬多少空气

CFM 是立方英尺每分钟，m³/h 是立方米每小时。二者都描述体积流量，换算约为：

`1 CFM ≈ 1.699 m³/h`

包装上标注的最大风量通常是在接近无阻力条件下得到的。安装滤网、冷排后，实际流量会变，不能把最大风量当成进入机箱的实际流量。

### 4.3 静压 mmH₂O：面对阻力时的能力

静压可帮助描述风扇建立压差的能力，常见单位为毫米水柱。滤网、冷排和鳍片越妨碍气流，越要关注风扇面对这些阻力时的表现。

最大静压通常在接近零流量的条件下测得；最大风量则通常在接近零静压时测得。**两项最大值不是风扇能同时达到的状态。** [ARCTIC 静压用途说明](https://www.arctic.de/en/faq/detail/What-is-static-pressure-important-for)

### 4.4 P-Q 曲线：真正的工作点在哪里

P-Q 曲线描述风扇在不同流量下能建立的压力；机箱与冷排也有随流量变化的阻力关系，两者配合决定实际工作点。

这解释了为什么两把最大风量接近的风扇，装在冷排上也可能差很多；最大静压较高，也不保证在所有中间流量区域都更好。

初学者不必先学会画曲线，可以先找同一冷排／滤网、同噪声条件下的可比测试。只列包装参数，无法完整回答实际散热好坏。

### 4.5 噪声：小数字要连测试条件看

dB(A) 是经过 A 加权的声压级，受距离、环境底噪和测量方法影响。不同厂商在不同条件下测得的标称值，不宜直接按 1dB 差距判胜负。

噪声还包括风噪、电机声、轴承声、特定频段音调和机箱共振。相同分贝也可能听感不同；风扇挨着格栅或面板，还可能出现额外声音。

分贝不能直接相加。理想情况下，两个相互独立、等声级的声源合计约比单个高 3dB，但真实装机环境和风扇相互作用会改变结果。

### 4.6 轴承：寿命与声音不能只认缩写

常见有含油轴承、滚珠轴承、流体动压轴承（FDB）及厂商自定义方案。结构会影响摩擦、姿态适应、噪声和耐久，但具体做工与使用温度同样重要。

“FDB”不自动保证所有转速都安静，“滚珠”也不意味着一定不适合家用。看保修、实际声音与安装方向要求，比背缩写更有用。

### 4.7 加更多风扇，为什么不是线性提升

并排工作的风扇偏向增加流量能力，前后串列偏向增加克服阻力的能力。但在机箱和冷排里，气流相互影响、阻力和泄漏使效果不能简单相加。

冷排前后各装一排的 push-pull，可能在特定条件下有益，不代表温度或风量翻倍。风扇不匹配、安装空间与额外噪声也要考虑。[Noctua 串联／并联说明](https://www.noctua.at/cn/expertise/tech/axial-fans-in-series-or-parallel-operation)

当原有换气已经满足需要时，再加风扇可能只有很小收益；如果气流路径不对，再多风扇也可能没有把凉空气送到热源。

## 五、🌬️ 理论：正叶、反叶与风道

### 5.1 正叶不等于排风，反叶不等于进风

正叶／反叶描述产品叶片与气流方向的设计关系；进风／排风描述装进机箱后空气朝哪里走。

同一把风扇翻面安装，就可以改变它相对机箱的进／排风作用。反叶的常见用途是让你在展示特定外观面时，仍能得到所需气流方向。

因此先决定“这里需要空气向哪里走”，再根据希望展示哪一面选择正叶或反叶。

### 5.2 如何判断方向

优先看外框的旋转与气流箭头，其次看该型号说明。常规扇的支架侧经验不能覆盖所有反叶、特殊结构产品。

安装前可根据说明和安全通电观察核对气流，不要把手指或松散纸条伸进叶轮。颜色、灯亮的位置和品牌贴纸不是通用方向标识。

### 5.3 先画空气路径，再数风扇

可以先用一句话描述目标：凉空气从侧面／底部进入，经过显卡等区域，再由顶部／后部排出。这是常见思路，具体要服从机箱结构和冷排位置。

空气可能从缝隙进出，也可能在近邻进排风口间短路。冷排作为进风或排风还有 CPU 与显卡之间的取舍，详见 [[6.散热|散热]]。

### 5.4 正压、负压不能按数量算

机箱的相对压力由实际进排风能力和机箱阻力共同决定。六把受滤网限制的低转进风扇，不一定压过三把高转排风扇。

合理的滤网进气可以帮助控制灰尘进入路径，但不保证无尘；追求正压也不能牺牲必要的有效换气。最终看部件温度、噪声与积灰情况。

## 六、🔌 理论：接线、供电与调速

### 6.1 电机线与灯效线是两套用途

| 常见接口 | 主要作用 | 注意事项 |
| --- | --- | --- |
| 3-pin 风扇接口 | 电机供电、接地与测速 | 常通过 DC 调压调速 |
| 4-pin PWM 风扇接口 | 增加专门 PWM 控制信号 | 不等于 4-pin RGB 灯效口 |
| 常见 5V 3-pin ARGB | 可寻址灯效 | 与电机调速无直接对应关系 |
| 常见 12V 4-pin RGB | 非逐灯寻址的 RGB 灯效 | 不能代替 5V ARGB |
| SATA 供电／专有多针口 | 控制器或设备的电源与组合连接 | 必须核对具体系统与接线说明 |

灯效 3-pin 与电机 3-pin 不是一回事。5V ARGB 不得接入 12V RGB，形状或针数相近也不能互插。[Phanteks 接口说明](https://phanteks.com/faq-items/why-are-digital-rgb-and-rgb-not-compatible/)

### 6.2 DC 与 PWM 怎样调速

DC 模式通过改变供电电压控制转速；常见 12V 四线 PWM 扇通常保持额定电源供电，通过第四根线的控制信号改变转速。

普通三线扇接兼容四针风扇口时，若主板支持 DC 模式，可按说明调压控制；单纯使用 PWM 模式，不会让没有控制线的三线扇自动获得 PWM 能力。

四线 PWM 扇也可能支持调压运行，但调速范围和表现要按产品说明。PWM 占空比 50% 不保证所有型号都正好转到最高转速的一半。[Noctua 接口兼容](https://www.noctua.at/cn/support/faqs/can-i-run-noctua-3-pin-fans-on-4-pin-pwm-connectors-or-4-pin-fans-on-3-pin-connectors)

### 6.3 分线器：一个信号控制多把，不一定逐个测速

普通被动分线器通常共享供电和控制信号。主板一个风扇口一般只接收其中一把的转速反馈，防止多个测速信号冲突。

所以某个分支少一根测速线可能是正常设计，不等于丢失 PWM 控制；但不能仅凭针数忽略核对线序。[Noctua 分线器说明](https://www.noctua.at/en/support/faqs/my-y-cable-is-missing-a-pin-at-one-of-the-two-connectors-is-it-faulty)

同样 PWM 信号下，不同型号可能转速不同。只读到其中一把的 RPM，也不证明其余风扇都转得一样或都运行正常。

### 6.4 集线器：区分外部供电与独立控制

部分集线器由 SATA 等外部接口供电，主板只提供控制与测速连接；普通外供电 PWM 集线器也可能只支持共享控制，不等于每口独立调速。

有些产品支持 USB 软件和独立通道，有些只控制灯效。购买时查清供电来源、端口功能、单口与总负载上限，以及断开软件后的行为。

### 6.5 电流：不能把一分多当成无限扩展

假设一把扇额定电机电流 0.20A，四把合计就是 0.80A。这只是算例，不是你现有风扇的规格。

还需考虑启动电流、附件以及接头和线材限制，按厂商规定核算。主板风扇口不都是统一 1A，不能拿别的型号说明书代替自己的主板。

灯效电流也要单独核算。外部供电集线器有自己的限制，不意味着电流无限或所有专有接口都兼容。

## 八、🔧 实践：从安装到调速验证

### 8.1 前置准备

记录机箱型号、CPU／显卡与冷排位置、各风扇完整型号和方向、电机与灯效电流、主板接头限制，以及集线器／控制器说明。

先画每个位置的气流箭头，再列控制分组：冷排风扇、显卡附近机箱进风、机箱排风等。分组的目的是便于按实际发热调节，不是所有机器都必须分成固定几组。

### 8.2 安装与接线

1. 断电后按孔位安装，核对螺钉长度，尤其不要让过长螺钉损伤冷排。
2. 按箭头和产品说明确认气流，检查叶片周围与线材间隙。
3. 核算电机、灯效及集线器负载，分别连接对应接口。
4. 检查普通分线器的测速分支，确保需要回传的那一路已连接。
5. 初次启动观察全部风扇，而不只看主板读到的一个 RPM。
6. 设置与设备相符的 DC／PWM 模式，再验证调速响应。

专有一线系统必须用明确兼容的线缆与控制器，不能因为插头能碰巧插入就混用。

### 8.3 风扇曲线：用可重复方法找到合适转速

先找到每组可稳定启动、持续运行的最低范围，再逐步提高控制值，观察实际 RPM 与声音。停转阈值与重新起转阈值可能不同，不要把能维持转动的最低值直接当成可靠起转设置。

选择能够代表该区域负载的温度来源：只盯 CPU 的机箱风扇，可能在显卡高负载而 CPU 较凉时没有提速。软件／主板是否支持 GPU 或其他传感器，要查实际能力。

CPU 瞬时温度跳动可能造成风扇反复加减速，可使用支持的迟滞、升降速延迟或平滑功能。[Noctua 调速说明](https://www.noctua.at/en/support/faqs/how-do-i-optimise-my-fan-settings)

### 8.4 完整实践：多加一组风扇有没有收益

1. 固定环境、机箱状态、BIOS、功耗与风扇控制方式。
2. 跑同一段游戏或真实持续任务，观察到温度和表现基本稳定。
3. 记录 CPU／GPU 温度、功耗、频率、任务成绩、各组 RPM 和声音感受。
4. 只改变一组风扇的数量、方向或转速，重复相同任务；一次只改一个因素。
5. 同时检查 CPU 与显卡：一边改善、另一边变差，是需要评估的取舍。
6. 比较同噪声附近的温度／成绩，或同目标温度下的噪声，决定是否保留改动。

假设多加两把后温度只低 1℃，但声音明显增大，就需要判断这点余量是否值得。这个数字只是教学例子，不是你的配置实测。

### 8.5 常见问题先查什么

| 现象 | 优先检查 |
| --- | --- |
| 灯亮，风扇不转 | 电机供电、控制值、停转功能与接口，不只检查灯线 |
| 风扇转，灯不亮 | 灯效供电、接口、电压、控制器和软件 |
| BIOS 只显示一把 RPM | 分线器／集线器是否只回传一路 |
| 所有风扇一直高速 | DC／PWM 模式、控制信号、接线与专有控制器 |
| 某些风扇同百分比却转速不同 | 型号差异、控制曲线、最低阈值和设备状态 |
| 一阵快一阵慢 | 温度来源、曲线斜率、迟滞与后台负载 |
| 风扇越多，温度没改善 | 气流短路、进气阻力、布局和其他散热瓶颈 |
| 特定转速嗡嗡响 | 框体接触、机箱共振、叶片与格栅相互作用 |

清洁时先断电，按说明处理积灰，避免线材接触叶片；不要让强气流把叶轮长时间吹到失控高速。

## 九、📌 看配置单时怎么追问

| 常见说法 | 应继续问什么 |
| --- | --- |
| 风量最大，这把最好 | 是自由风量还是经过滤网／冷排的风量？ |
| 静压更高，一定更安静 | 是什么转速和噪声下得到的？ |
| 反叶都是进风 | 最终朝哪边装，箭头指哪里？ |
| PWM 就一定能停转 | 具体型号和控制器是否支持？ |
| 一个口能接很多把 | 主板、线材、集线器的供电限制是多少？ |
| 有八把就是强风道 | 实际路径、阻力、转速与温度怎样？ |
| 轴承好就不会吵 | 电机音、风噪、共振与测试条件怎样？ |

**记忆路线：定安装位置 → 看阻力与空间 → 配风量／风压 → 选方向 → 核对供电控制 → 用温度和噪声验证。**
