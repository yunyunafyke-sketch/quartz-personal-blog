## 一、💡 先建立判断标准

> [!tip] 核心结论
> 散热的目标是在你的实际负载下，让硬件以可接受的温度、噪声和稳定性持续工作。散热器更贵、更大，可能增加余量或降低噪声，但不保证电脑明显更快。

本文面向已经会基本装机、想理解搭配原因的人。按“热怎样排出去 → 风冷与水冷 → 参数 → 机箱风道 → 你的配置 → 安装与验证”展开，以 CPU 散热为主，同时说明整机散热。

主线案例：你的 13600KF 主机记录为瓦尔基里 GLA240 黑色数显款，14600KF 主机记录为华硕 PRIME LC 360 ARGB 白色款。为什么 240 可以成为候选，360 又多提供了什么？

资料核对日期：2026-10-25。案例不是实时价格排名，也不表示已测试你的机器温度与噪声。

## 二、🧭 理论：热量究竟往哪里走

### 2.1 CPU 发出的热，不会被散热器“消灭”

CPU 工作消耗电能，其中很大部分最终转化为热。散热系统要把热从芯片附近传到周围空气，再通过通风排到房间。

普通风冷／一体式水冷都不是制冷机。在稳定负载下，它们不能让 CPU 依靠室内空气冷却却长期低于环境温度。

可以把散热类比为搬运链：热源、接触面、传热结构、散热表面、空气流动，任何一段阻力过大，都可能限制整体效果。这个类比只描述能量传递，真实温度还受热容量与瞬态负载影响。

### 2.2 两条传热路径

| 方案 | 简化路径 | 最终往哪里散热 |
| --- | --- | --- |
| 风冷 | CPU → 顶盖 → 导热材料 → 底座／热管 → 鳍片 → 空气 | 机箱内空气，再与室内交换 |
| 一体式水冷 | CPU → 顶盖 → 导热材料 → 冷板 → 冷却液 → 冷排 → 空气 | 经过冷排的空气，再与室内交换 |

两者最终都靠空气带走热量，所以水冷仍然需要合适风扇和机箱通风。水本身不是无限吸热的黑洞。

### 2.3 为什么水冷刚开始温度好看，持续测试还要等

冷却液和散热结构可以暂时储存热量。开始负载时，水温较低，随后逐渐升高，直到散热与输入热量接近平衡。

因此只跑几十秒的测试，不能完整代表长时间渲染、编译或烤机表现。比较时应观察温度、功耗和频率是否趋于稳定，并记录运行时长。

## 三、🔎 理论：风冷、水冷与型号怎么看

### 3.1 下压式、单塔、双塔风冷

| 类型 | 常见结构 | 可以考虑什么 | 需要注意什么 |
| --- | --- | --- | --- |
| 下压式 | 风扇向主板方向送风 | 限高机箱、部分周边供风需求 | 具体高度、热负载与机箱进气 |
| 单塔 | 一组主要鳍片塔配风扇 | 常规安装空间与负载需求 | 塔高、内存和侧板兼容 |
| 双塔 | 两组主要鳍片塔 | 更大换热面积与噪声余量 | 宽度、重量、内存遮挡和风扇位置 |

单塔不必然差、双塔也不必然安静。底座、热管、鳍片、风扇和安装质量共同决定效果，不能只数塔和热管。

风冷热管通常借助内部工质的蒸发、冷凝和回流传热，不是普通实心铜棒；实际表现还受结构、负载与安装方向影响。

### 3.2 一体式水冷与分体水冷

一体式水冷（AIO）将冷头、管路、冷排和泵组成预封装系统，用户主要完成固定与接线。普通装机通常不需要自行加液或拆开管路。

分体水冷需要单独规划冷头、水泵、水箱、管路和冷排等，安装与维护要求更高，不是入门装机提升性能的必要步骤。

水冷多了液体循环与水泵，可能获得布局和换热面积优势，也增加泵噪声、老化及故障等需要考虑的因素。保修、维护和更换便利应一起比较。

### 3.3 120、240、280、360、420 是什么

| 规格叫法 | 常见风扇组合 | 不代表什么 |
| --- | --- | --- |
| 120 | 1×120mm | 不代表和大冷排性能同级 |
| 240 | 2×120mm | 冷排实际长度不一定就是 240mm |
| 280 | 2×140mm | 不一定装得进支持 360 的位置 |
| 360 | 3×120mm | 不代表比 240 强固定百分比 |
| 420 | 3×140mm | 机箱支持 360 不表示也支持 420 |

名称主要对应风扇安装规格，冷排还有端水室等结构，实际长宽厚与风扇厚度必须查完整产品尺寸。

同一系列、相近设计下，更大冷排通常提供更多换热面积；但 360 与 280、240 的实际差距，还受冷排厚度、鳍片、风扇、泵和噪声条件影响。

### 3.4 带屏幕、ARGB、白色：哪些在提升性能

屏幕、灯效和颜色主要影响外观与信息展示，不能直接变成散热能力。屏幕显示的温度还要确认读取的是 CPU、冷却液还是其他传感器，不能与另一款读数直接比较。

“数显”“LCD”“Pro”“旗舰”等名称没有跨品牌统一散热等级。选择时记录完整型号、尺寸、扣具、接线、保修与有说明条件的测试。

## 四、⚙️ 理论：温度、噪声和性能怎么联系

### 4.1 为什么不能看 CPU 的一个瓦数选散热

CPU 基础功耗、最大睿频功耗、实际封装功耗与散热器宣传的“解热功耗”，不是统一测试条件下的一组相同数字。

你的 13600KF、14600KF 官方基础功耗均为 125W，最大睿频功耗均为 181W；实际负载还受 BIOS 规则、程序和散热条件影响，不能按 125W 就认定任何标称 125W 散热器都合适。

不同厂商对散热器瓦数的测试条件也可能不同。Noctua 因此使用自家 NSPR 与具体 CPU 兼容评级帮助比较，但 NSPR 同样不是所有品牌通用的标准分数。[Noctua 评级说明](https://www.noctua.at/en/expertise/guides/noctua-standardised-performance-rating)

### 4.2 相同功耗，不同 CPU 温度也可能不同

热源面积、芯片布局、顶盖与内部导热路径都会影响热从芯片传出来的难度。功耗相同，不代表热集中程度相同。

所以不能拿两个不同 CPU 的温度，直接比较散热器谁更强；也不能因为小功耗 CPU 温度高，就认定它比高功耗 CPU 向房间释放更多热。

### 4.3 温差：先把室温记下来

相同负载和设置下，室温越高，散热系统面对的冷空气条件越差。可以用“CPU 温度减环境温度”辅助比较，但芯片功耗、风扇和安装也要控制。

例如两次都是 80℃：室温 20℃ 时温差是 60℃，室温 30℃ 时温差是 50℃。不能只看 CPU 温度一样就断言散热条件完全相同。

简单稳态模型可写作：

`温升 ≈ 热功率 × 等效热阻`

它只帮助理解。真实电脑的热阻随风量和工况变化，功耗与风扇也会动态调节，不能用一次读数反推出普遍能力。

### 4.4 高温、降频与“正常”怎么区分

CPU 有温度管理机制，接近特定限制时可能降低功耗或频率。不同型号温度上限不同，应查官方规格。

你两颗 CPU 的官方 Tjunction 上限为 100℃，但这不是建议所有负载都必须贴着 100℃运行的目标，也不能据此把任何接近上限的情况直接判为故障。

Intel 官方明确说明，不能仅凭温度单独判断散热方案是否有问题。还要结合负载、实际功耗、频率、限速标记、稳定性和噪声。[Intel 温度说明](https://www.intel.com/content/www/us/en/support/articles/000005597/processors.html)

### 4.5 散热更好，为什么有时温度没降，成绩却提高

部分处理器会利用温度、功耗与电流余量提高工作频率。散热改善后，可能消耗更多功率、完成更多工作，而温度仍接近原先水平。

也可能表现为同样成绩下温度更低，或同样温度下风扇更安静。要同时看性能、功耗、温度与噪声，而不是只找一个最低温。

原来没有受温度限制时，换大散热器的主要收益可能是噪声和余量；不能承诺游戏帧率一定明显增加。

### 4.6 风量、静压、转速：不同参数解决不同问题

| 参数 | 主要描述什么 | 常见误解 |
| --- | --- | --- |
| 风量，常见 CFM | 输送空气的能力，最大值通常来自低阻力条件 | 最大风量能无损穿过任何冷排 |
| 静压，常见 mmH₂O | 克服阻力的能力，最大值通常接近零风量条件 | 最大风量与最大静压能同时获得 |
| RPM | 每分钟转数 | 所有风扇转速相同就效果相同 |
| dB(A) | 特定条件下测得的 A 加权声压级 | 不同厂商标称数字一定能直接比较 |

风扇装到冷排、滤网或密集鳍片上后，实际工作点由风扇与阻力共同决定。应关注对应场景的性能，不是把包装上的几个最大值相乘。[ARCTIC 风量与静压说明](https://www.arctic.de/en/faq/detail/Static-pressure-and-airflow-in-fans-what-exactly-does-that-mean)

### 4.7 为什么“同噪声比较”很重要

一款散热器如果靠很高转速取得低温，未必比另一款在较低噪声下的表现更适合你。公平测试可以比较同噪声下的温度／功耗能力，也可以比较相同负载和温度目标下的噪声。

噪声还包括泵、轴承、气流、啸叫和机箱共振。分贝是对数量，不能把两个风扇的分贝直接相加；手机录音也不足以精确比较不同距离与环境下的声压。

### 4.8 硅脂：填微小空隙，不是越厚越好

CPU 顶盖与冷板看似平整，微观仍有不平与空隙。导热材料用来改善接触，减少空气夹层影响；它不能代替散热器。[Intel 导热材料说明](https://www.intel.com/content/www/us/en/support/articles/000037209/processors.html)

预涂材料完好时按产品说明直接安装，不必再叠加一大层。涂抹方法和用量按 CPU、材料和散热器说明，不能把某种点法套到所有尺寸。

拆下重新安装时，应按材料说明清理接触面并重新处理导热材料。不要仅凭宣传导热系数判定整机效果，更不要把液态金属当成普通硅脂随意替换。[Noctua 涂抹与清理说明](https://www.noctua.at/en/support/faqs/how-should-i-apply-the-nt-h1-or-nt-h2-thermal-paste-on-the-cpu-and-how-can-i-remove-it)

## 五、🌬️ 理论：机箱风道与水冷位置

### 5.1 CPU 散热器不是整机唯一热源

显卡、VRM、SSD 等也会发热。更大的 CPU 冷排不能替代显卡进气与机箱整体通风。

例如 CPU 水冷温度不错，显卡却一直吸入积聚热风，整机仍可能很吵。应观察主要发热部件各自的进气来源和热风去向。

### 5.2 进风与排风：看气流路径，不只看数量

常见思路是前／侧／底部引入空气，再由后部／顶部排出，但实际方向必须结合机箱结构、滤网、显卡和冷排位置。

风扇直接推动的气流通常比“热空气自然上升”更能决定机箱内主要流向。不能只凭热空气上升就决定所有风扇方向。

进风过后若立刻从旁边排出、没有经过需要冷却的区域，就可能形成低效路径。风扇数量更多也可能只增加噪声，并不必然提高有效换气。

### 5.3 正压、负压：不是数几把风扇

正压通常指机箱内部相对环境略高的压力，负压则相反。决定因素是风扇工作点、转速、滤网和机箱阻力，不能单看进风扇比排风扇多一把。

合理的带滤网进气可以帮助灰尘管理，但不保证完全无尘。负压也不等于一定散热更强，仍要看实际气流和温度。

### 5.4 正叶、反叶：与进风排风不是固定绑定

反叶产品改变叶片设计，使气流方向与常规产品的外观关系不同，常用于兼顾展示面和进气需求。

一把扇装在机箱上到底进风还是排风，取决于它的实际气流方向和安装朝向。优先看框体箭头和型号说明，不能统一按“有支架的一侧出风”判断所有正反叶产品。

你的记录有正叶和反叶数量，但仅凭购买数量不能确认最终风道，也不能推断每把风扇安装方向。

### 5.5 冷排进风还是排风：在冷却对象之间取舍

| 布置思路 | 可能的好处 | 可能的代价 |
| --- | --- | --- |
| 冷排作为进风 | 冷排接触较凉的室内空气 | 热量进入机箱，可能影响显卡等部件进气 |
| 冷排作为排风 | 把经过冷排的热风直接排出 | 冷排可能使用已经被显卡加热的机箱空气 |

这不是固定排名。侧置、前置、顶置都需要结合机箱与实际负载测试，CPU 与显卡同时工作时尤其要观察整机结果。

### 5.6 水泵、气泡与安装高度

以水泵位于 CPU 冷头中的常见 AIO 为例，设计上应避免泵成为回路最高处，让空气更容易停留在冷排高处，而不是持续进入泵。顶置冷排、或合适的前置且接口向下，都是常见布置思路。[Corsair 安装说明](https://help.corsair.com/hc/en-us/articles/360049358271-AIO-How-should-I-mount-the-radiator-of-my-AIO-cooler)

但并非所有水冷的泵都在冷头里，实际泵位置与安装要求必须查具体产品说明。前置接口向上也不能简单等同于必坏，关键还包括泵与冷排最高点的相对位置、液量与实际设计。

不要为了套用通用口诀，把管路拉紧、强行弯折或安装在说明禁止的位置。

## 六、📋 你的 240／360 水冷怎么理解

### 6.1 已有记录与未知项

| 项目 | 13600KF 主机 | 14600KF 主机 |
| --- | --- | --- |
| 散热器记录 | 瓦尔基里 GLA240 黑色数显款 | 华硕 PRIME LC 360 ARGB 白色款 |
| 规格类别 | 240mm 一体式水冷 | 360mm 一体式水冷 |
| 机箱记录 | 乔思伯 TK1+ | 爱国者星璨辰屏显版 |
| CPU 官方最大睿频功耗 | 181W | 181W |
| 待验证 | 实际温度、频率、功耗、风扇／泵状态 | 实际温度、频率、功耗、风扇／泵状态 |

来源：[[diy主机/diy-13600kf+5060]]、[[diy主机/diy-14600kf+5070]]。GLA240 按现有记录确认，不把订单标题中的 GLA360 当成实际安装规格。

本文未取得 GLA240 对应完整官方技术说明，不填写未经核对的泵速、风量、保修或所谓解热功耗。

### 6.2 为什么 240 可以成为候选，360 又提供什么

你的两颗 CPU 最大睿频功耗相同，但实际游戏与持续多核任务的发热不同。合适的 240 是否够用，要由机箱风道、安装、功耗规则和真实负载验证，不能从“i5”或“240”直接得出结论。

360 通常提供更多冷排面积，有机会在同等热负载下使用较低风扇转速，或承担更高持续热量；但不同产品不能只按 360÷240 算成提升 50%。

你的两台电脑还更换了显卡、机箱和风扇，因此直接比较两台 CPU 温度，无法隔离 240 与 360 本身的差异。

### 6.3 为什么冷排尺寸不能只看“360”

华硕 PRIME LC 360 ARGB 系列官方规格列出的冷排尺寸为 397×120×27mm：这说明 360 的名称并非实际总长度。具体白色版与包装型号仍应对照对应规格页及实物。

安装还要叠加风扇厚度、接头和管路空间，检查顶部是否碰内存／主板散热片，侧置或前置是否压缩显卡空间。机箱写“支持 360”，也不能省略这些检查。

### 6.4 风冷与水冷怎样选更合理

| 需求 | 可优先比较的方向 | 仍需核对 |
| --- | --- | --- |
| 普通负载，希望结构简单、维护便利 | 合适的单塔或双塔风冷 | CPU 持续负载、塔高、内存和侧板 |
| 持续多核负载，机箱有冷排空间 | 较强风冷与合适 AIO 对比 | 同噪声表现、持续功耗、位置和保修 |
| 小机箱 | 按机箱结构选择下压风冷或 AIO 等 | 不能只看宣传支持，需检查全部尺寸 |
| 强调展示与外观 | 选择愿意为其外观付费的方案 | 屏幕与灯效成本不要当成性能收益 |

风冷和水冷都可能适合游戏、开发与创作，关键是具体型号和工况。不存在“高端 CPU 一定必须水冷”或“所有水冷一定更安静”的通用结论。

## 七、🔧 实践：安装、调节与验证

### 7.1 前置准备：兼容检查

记录 CPU 插槽、主板型号、机箱散热限高／冷排支持、内存高度、显卡尺寸、电源与接头，以及期望噪声和负载。

确认扣具和支架明确支持该平台，不要只因孔位接近就强行安装。查看风扇、水泵、USB、SATA 供电与 ARGB 具体接线；某根 3-pin 线可能只输出测速信号，不能仅凭针数判断全部供电方式。

### 7.2 安装检查：先让传热链正常工作

1. 按说明安装背板、支柱和扣具，核对零件方向。
2. 检查接触面保护膜；不要把说明要求保留的标签误认成保护膜。
3. 使用合适导热材料，按指定顺序均匀固定，不盲目加力。
4. 检查风扇方向、管路弯曲与显卡／内存干涉。
5. 按说明接好风扇和泵的电源、控制与测速线，核对主板单口负载。
6. 首次启动进入监控，确认温度、风扇／泵信号没有明显异常，再运行持续负载。

CPU_FAN、AIO_PUMP 与集线器的具体接法按主板和散热器说明。不能把灯效亮、屏幕亮当成水泵正常循环的证据。

### 7.3 风扇曲线：避免温度短跳就忽快忽慢

CPU 温度可以随瞬时负载快速变化。风扇曲线若响应过于激进，可能频繁拉高转速，听感反而不好。

可以在支持的控制界面中使用合理的升降速延迟／迟滞，逐步找到温度与噪声平衡。若有冷却液传感器并且产品支持，可按其说明利用水温控制冷排风扇；不能假设所有 AIO 都有水温读数。

泵速按厂商建议和控制方案设置，不要为了安静直接停泵，也不要把“水泵必须永远 100%”当成所有设计的唯一规则。

### 7.4 完整实践：判断散热是否需要升级

1. **固定条件：**同一室温附近、同一机箱状态、BIOS、功耗规则、内存与后台任务。
2. **建立任务：**选择常玩的游戏或实际编译／渲染任务，额外压力测试只作补充。
3. **记录起始状态：**环境温度、CPU 温度、封装功耗、频率、风扇／泵转速和任务成绩。
4. **持续观察：**运行到温度和表现基本稳定，记录时长、限速标记与异常；AIO 同时关注热积累。
5. **只改一项：**例如改变风扇曲线或一组风扇方向，再跑同任务，不要一次改动全部因素。
6. **比较结果：**性能是否恢复、温度是否改善、噪声是否可接受；同时看显卡和其他部件有没有变差。
7. **再决定购买：**先排除接触、风道、积灰与功耗设置问题，再判断更大散热器能解决什么。

临时打开侧板对照，可能帮助发现机箱进排气限制，但也改变了噪声与气流条件，不能直接等同于开放状态就是最佳长期方案。

### 7.5 常见现象先查什么

| 表现 | 优先检查 |
| --- | --- |
| 刚加载就迅速高温 | 负载与功耗、冷板接触、保护膜、扣具和泵状态 |
| 跑一阵才明显变热 | 冷却液热积累、冷排进气、风扇曲线和机箱热风 |
| 温度低但很吵 | 风扇曲线、泵转速、轴承声、共振与气流阻力 |
| CPU 好看但显卡更热 | 冷排进风热量、显卡进气与排风路径 |
| 风扇很多但仍然闷 | 方向、滤网、遮挡、有效气流路径 |
| 冷头有异响 | 安装高度、气泡、泵速与厂商排查步骤 |
| 温度没变但任务更快 | 是否利用了新的温度余量提升功率／频率 |

如果检测到泵不工作、明显泄漏或温度异常快速上升，应停止负载并按厂商说明排查。不要让机器继续重负载来“观察会不会自己好”。

### 7.6 清洁与维护

定期按环境检查滤网、鳍片和冷排积灰，断电后按说明清洁；不要让强气流把风扇持续吹到失控高速。

硅脂是否需要重涂、AIO 是否需要更换，应结合材料说明、运行年限与表现，不设所有产品统一的半年或一年期限。封闭 AIO 不擅自拆开加液，售后范围以对应产品条款为准。
